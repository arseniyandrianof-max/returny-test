# returny для Windows и Mac

[Открыть лендинг](https://arseniyandrianof-max.github.io/returny-test/) · [Скачать returny](https://arseniyandrianof-max.github.io/returny-test/download.html)

На странице загрузки выберите Windows x64 (ZIP 1.1.2), Mac с чипом Apple M-серии или Mac с Intel (DMG 1.1.0). Все три файла доступны без входа в GitHub. На Windows распакуйте ZIP целиком и запустите `returny.cmd`. На Mac проверьте тип чипа в меню Apple → «Об этом Mac», откройте соответствующий DMG и перетащите returny в «Программы». У Mac-сборок локальная подпись, поэтому macOS может ограничить первый запуск.

Чтобы пройти тестовое оформление за 0 ₽, откройте миниапп с лендинга. Статический стенд работает на GitHub Pages. Восстановление приложения на iPhone выполняется на компьютере по USB с аккаунтом покупок пользователя.

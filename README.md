# returny для Windows

Открытый стенд для проверки загрузки настольного приложения. Тестовый заказ стоит 0 ₽. Пройдите подтверждение в браузере, скачайте ZIP, распакуйте его целиком и откройте `returny.cmd` на Windows x64.

[Открыть тестовый миниапп](https://arseniyandrianof-max.github.io/returny-test/mini.html) · [Windows-сборка 1.1.0](https://github.com/arseniyandrianof-max/returny-test/releases/tag/v1.1.0)

Статические страницы работают на GitHub Pages. Этот стенд не принимает деньги или данные карт. Для восстановления на iPhone используется настольное приложение и собственный аккаунт покупок Apple.
